# 游戏美术指导图生成向导设计

## 1. 目标

在不增加独立多模态分析服务的前提下，复用现有图片生成模型和参考图能力，将风格方向整理成可供后续资产生产使用的视觉指导材料。

用户只需要完成参考图选择和生成设置。系统负责生成视觉基因锚点、专业模块图、综合指导图，并将实际提示词、参考图、模型参数和 MCP 素材 ID 保存到指导包草稿。

## 2. 设计原则

- 图片模型只负责视觉归纳和设计延展，不承担可靠长文字生成。
- 中文标题、模块名称、色板信息和状态说明由本地排版器生成。
- 综合指导图面向人阅读，不作为默认模型参考图。
- 后续生产优先引用“视觉基因锚点＋当前专业模块图”，智能平衡模式通常不超过两张图。
- 每个生成节点只生成一张图片；失败时只重试受影响节点。
- 所有生成结果保留 MCP 素材 ID，后续引用不得重新上传。
- 生成结果先写入指导包草稿，用户发布后才形成不可变版本。

## 3. 浮窗总体结构

指导包编辑工作区提供“生成视觉指导图”入口。点击后打开独立生成向导浮窗。

顶部固定显示三步进度条：

`① 选择参考图 —— ② 生成设置 —— ③ 生成指导图`

步骤状态：

- 已完成：实心节点和完成状态，可点击返回。
- 当前步骤：高亮节点及数字。
- 未开启：灰色空心节点；点击时提示完成当前步骤所需条件，不直接跳转。
- 返回前一步修改输入后，后续任务和结果标记为“输入已变更”，不得直接写入指导包。

浮窗使用稳定宽高和内部滚动，不因参考图数量或任务节点数量改变外框尺寸。

## 4. 第一步：选择参考图

### 4.1 主浮窗布局

第一步不长期展示完整素材网格，只显示：

- 已选参考图缩略图条；
- `已选数量 / 当前模型参考图上限`；
- “选择参考图”“清空”操作；
- 素材不可用、超过模型上限或缺少远端素材 ID 时的提示；
- “下一步”按钮。

没有已选图片时显示明确空状态，不擅自选择系统无法可靠判断的图片。

### 4.2 二级参考图选择弹窗

点击“选择参考图”打开二级弹窗，复用图片生成现有参考图管理规则：

- 来源包括当前风格方向的参考图和成功生成结果；
- 按共享画布分组组织 16:9 图片网格；
- 分组支持折叠、展开和分组批选；
- 折叠后仍显示该组已选数和总数；
- 卡片按原比例完整显示，不裁切主体；
- 卡片左上角显示“参考图”或“生成结果”；
- 右上角复选框独立负责选中；
- 点击图片主体打开全局大图预览，不同时改变选择状态；
- 底部固定显示已选数量、取消和确认。

确认后把临时选择同步回主浮窗。取消只关闭二级弹窗，不改变进入弹窗前的选择。

`Escape` 按层级关闭：先关闭大图预览，再关闭二级选择弹窗，最后才允许关闭生成向导。关闭二级弹窗不得丢失主浮窗中的模式和参数。

## 5. 第二步：生成设置

### 5.1 生成模式

提供两种互斥模式：

#### 整体生成

一次图片生成得到包含所选模块的综合视觉图，再由本地排版器整理为正式模板。

优点是模型调用少、速度快；限制是后续缺少专业模块图，专项生成精度低于分模块模式。

#### 分模块生成

先生成视觉基因锚点，再基于锚点和来源参考图生成各专业模块图，最后由本地排版器生成综合指导图。

这是默认和推荐模式。

### 5.2 模块选择

模块固定为：

1. 视觉基因；
2. 场景与环境；
3. 角色与生物；
4. UI / HUD；
5. 技能与 VFX；
6. 道具与装备。

默认全选。

- 分模块模式下“视觉基因”固定启用，其余五个专业模块可以切换。
- 整体模式允许选择综合图需要包含的模块；至少保留一个模块。
- 关闭模块时不删除指导包中已有内容，只影响本次生成运行。

### 5.3 提示词查看

主浮窗只显示提示词摘要和“查看完整提示词”入口。

完整提示词使用独立弹窗展示，分为：

- 母提示词；
- 当前模式及模块扩展；
- 负面约束；
- 实际参考图顺序。

第一版提示词只读，支持复制。任何后续开放的临时编辑都必须保存为本次运行覆盖，不得回写系统模板或已发布指导版本。

### 5.4 生成参数

底部固定参数区包含：

- 图片模型；
- 宽高比；
- 分辨率；
- 背景；
- 预计图片任务数；
- 预计参考图数量及可见降级说明。

生成数量固定为每个节点一张。

- 整体模式默认使用模型支持的最接近方形比例。
- 分模块模式默认使用模型支持的横向比例。
- 用户可以调整比例，但所有生成节点默认共享同一组参数。

“开始生成”提交前必须再次验证参考图、模型能力、模块选择和任务数。

## 6. 第三步：动态生成

第三步在主步骤条下展示本次运行的动态任务链。

### 6.1 整体生成任务链

`生成综合视觉图 → 本地模板整理`

只有第一个节点调用图片模型。第二个节点使用本地排版器添加准确中文标题、模块标识、色板和来源信息。

### 6.2 分模块生成任务链

`视觉基因锚点 → 已勾选专业模块图 → 本地模板整理`

- 锚点必须先成功。
- 锚点成功后，专业模块任务可以并行提交。
- 界面按场景、角色、UI、技能特效、道具装备的固定顺序展示节点。
- 未勾选模块不生成节点。
- 全部必需节点成功后才启动本地模板整理。

### 6.3 节点状态与操作

每个节点支持：

- 等待；
- 提交中；
- 生成中及进度；
- 成功及结果缩略图；
- 失败及安全错误信息；
- 单节点重试；
- 查看大图。

规则：

- 锚点失败时不启动下游模块。
- 专业模块失败时，只重试失败模块。
- 用户重新生成锚点后，已有专业模块结果标记为“基于旧锚点”，必须重新生成或由用户明确保留。
- 已选模块尚有失败或未确认节点时，不允许写入指导包。

### 6.4 完成操作

模板生成成功后展示：

- 综合指导图预览；
- 本次使用的模型、提示词和参考图摘要；
- 已生成模块列表；
- “写入指导包草稿”主操作；
- “返回调整”操作。

写入草稿不会自动发布指导包。

## 7. 图片生成提示词策略

系统维护一份母提示词，并按模式和模块追加固定要求。

母提示词目标：

- 严格沿用来源参考图的媒介、色彩关系、形状语言、细节密度、材质、光照和重复视觉母题；
- 生成原创设计，不复制参考图中的具体角色、建筑和构图；
- 同一次运行保持像素密度、描边、透视和材质表达一致；
- 不生成标题、标签、说明文字、伪文字和水印；
- 使用中性背景和清晰对象间距，便于本地排版。

模块扩展分别约束：

- 视觉基因：代表性世界缩影、色彩关系、形状语言、材质样本和光照变化；
- 场景：建筑、地形、植被、水体、天气、构图层次和可交互区域；
- 角色：主角、NPC、敌对生物、轮廓、比例、服装材质、姿态和动作；
- UI：HUD、物品栏、任务面板、按钮状态、图标体系和无文字占位区；
- 技能特效：起手、持续、命中、消散、元素颜色和战斗可读性；
- 道具装备：武器、装备、消耗品、交互道具、材质和品质差异。

整体模式把所选模块压缩进一份综合构图要求。分模块模式只提交母提示词和当前模块要求，不把其他模块文本一并发送。

## 8. 参考图路由与成本控制

第一步保存用户确认的候选集合。运行时根据模型上限进行确定性路由：

- 锚点图优先使用用户排序靠前且职责互补的来源图；
- 专业模块优先使用锚点图，再补充一张对应模块来源图；
- 当前模型只支持一张参考图时，专业模块优先使用锚点图，并展示降级提示；
- 综合指导图不作为默认模型参考输入；
- 分模块模式后续资产生产使用锚点图加对应模块图，智能平衡通常为两张；
- 整体模式只有综合视觉图时，可以作为单张 `core/overview` 通用参考，但界面标记“专项精度较低”。

产品界面始终默认全选六个模块。首次功能验收可以由测试人员手动只保留视觉基因、场景与环境、UI / HUD，以三张图片完成低成本校准；这不是面向用户的默认状态。

## 9. 本地模板整理

本地排版器负责：

- 准确中文标题和模块名称；
- 模块图片排版；
- 从图片像素确定性提取主色板；
- 展示方向名称、来源图数量、模型和生成时间；
- 使用方向描述、系统模块名称和本次提示词摘要生成可编辑说明；
- 输出综合指导图。

系统不得声称图片模型已经产生其实际没有返回的结构化文字分析。

## 10. 数据模型

新增持久化的视觉指导图生成运行，至少保存：

- 运行 ID、项目 ID、指导包 ID、方向 ID；
- 当前步骤和运行状态；
- 整体或分模块模式；
- 已选模块；
- 模型和生成参数；
- 来源参考图快照及 MCP 素材 ID；
- 母提示词、模块提示词和负面提示快照；
- 每个动态节点的生成记录 ID、状态、结果路径和远端素材 ID；
- 输入修订号和失效原因；
- 最终模板路径；
- 创建、更新时间和操作者。

运行必须可在刷新页面后恢复，不得只保存在前端内存。

写入指导包草稿时生成结果按职责登记：

- 锚点图：`core/style-anchor`；
- 综合图：`core/overview`；
- 场景：`environment/composition-material-lighting`；
- 角色：`character/silhouette-costume-pose`；
- UI：`ui_hud/layout-frame-icon-color`；
- 技能特效：`skill_vfx/timing-shape-color-readability`；
- 道具装备：`props_equipment/shape-material-rarity-function`。

## 11. API 与服务边界

视觉指导图运行由独立编排服务负责，不把状态机塞入前端：

- 创建运行并验证输入；
- 提交锚点或整体图片任务；
- 锚点完成后提交模块任务；
- 聚合任务状态；
- 标记输入变更和下游失效；
- 调用本地模板排版器；
- 将结果应用到指导包草稿。

图片生成继续复用现有 OmniGen 服务、任务历史、素材 ID 解析和文件指纹缓存。

建议接口：

- `POST /api/v1/projects/{projectId}/style-guides/{packageId}/visual-runs`
- `GET /api/v1/projects/{projectId}/style-guides/{packageId}/visual-runs/{runId}`
- `POST /api/v1/projects/{projectId}/style-guides/{packageId}/visual-runs/{runId}/nodes/{nodeId}/retry`
- `POST /api/v1/projects/{projectId}/style-guides/{packageId}/visual-runs/{runId}/apply`

## 12. 错误与恢复

- 来源文件丢失：阻止开始并定位具体图片。
- MCP 素材 ID 失效：只自动修复一次；失败后保留运行并显示可操作错误。
- 参考图超过模型上限：生成前显示实际使用顺序，不静默声称全部使用。
- 锚点失败：下游保持等待，不创建重复任务。
- 模块失败：其他成功模块保持有效。
- 本地模板整理失败：不重新调用图片模型，只重试本地节点。
- 页面刷新或服务重启：从持久化运行和生成历史恢复。
- 用户关闭浮窗：任务继续运行；重新打开后回到第三步。
- 用户修改上游输入：增加输入修订号并标记旧结果，不覆盖旧历史。

## 13. 验收标准

1. 向导严格包含选择参考图、生成设置和生成指导图三个大步骤。
2. 二级参考图弹窗复用现有分组、选择和大图预览规则。
3. 未开启步骤不能跳过，返回修改输入后旧结果不会被错误应用。
4. 整体模式只调用一次图片生成，并经过一个本地模板节点。
5. 分模块模式先完成锚点，再生成所选专业模块，节点数量随选择动态变化。
6. 分模块模式视觉基因固定启用，其他模块默认全选并可关闭。
7. 提示词通过独立弹窗查看，不挤压主布局。
8. 每个节点只生成一张图，失败节点可以单独重试。
9. 页面刷新后仍可恢复运行状态和结果。
10. 生成结果保留 MCP 素材 ID，后续引用不重复上传。
11. 综合图使用本地准确文字，不依赖图片模型生成文字。
12. 写入草稿不自动发布，发布版本继续保持不可变。

## 14. 验证等级

本功能涉及后端 API、持久化状态机、生成任务编排、MCP 素材复用、文件输出和跨模块 UI，实施验证等级为 `L3（完整回归）`。

实施确认时需要明确列出：

- 视觉运行服务和状态机单元测试；
- 整体与分模块 API 测试；
- 参考图上限、素材 ID 复用、失败重试和恢复测试；
- 向导步骤、二级选择弹窗、动态节点和输入失效前端测试；
- 根目录 8895 页面浏览器验收；
- 现有生成、指导包、历史和项目服务回归。
