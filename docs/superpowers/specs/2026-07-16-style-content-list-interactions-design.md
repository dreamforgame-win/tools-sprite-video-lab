# 风格探索内容列表交互统一设计

## 目标

统一风格探索列表、画布、详情面板与右键菜单中的图片操作，补齐列表拖拽分组和快捷菜单，同时确保列表与画布继续读写同一份项目画布数据。

## 图标与命令

- 同一动作只保留一份图标定义和一条命令处理路径。
- 加入资产管理、移入回收站复用左侧导航的资产管理和回收站图标造型。
- 查看大图、重新生成、下载、调整分组和移动/复制在列表、画布、详情及右键菜单中使用相同图标。
- 画布中的字符放大符号替换为统一的放大图标。

共用内容操作为：查看大图、调整分组、移动/复制到方向、移入回收站。

生成结果额外提供：重新生成、设为封面、加入资产管理、下载。

参考图额外提供：重命名。

锁定、对齐、组内排列、缩放和适应视口属于画布空间操作，不进入列表批量操作。

## 列表拖拽分组

- 仅图片内容可拖动，便签不参与图片分组拖拽。
- 拖到具名分组即加入该组，拖到“未分组”即移出分组；拖回当前分组不执行写入。
- 使用原生桌面拖拽事件配合自定义缩略图拖影，让图片跟随指针。
- 拖动期间目标分组整体高亮，并显示“移到「分组名」”或“移出分组”的状态提示。
- 若当前卡片属于多选集合，则拖动全部已选图片；否则只拖动当前图片。
- 列表批量工具增加“调整分组”，与单图右键菜单共用分组选择逻辑。
- 分组修改直接更新对应画布节点的 `group_id`，创建分组时同时写入画布 `groups`；修改后持久化画布并局部重绘列表。

## 右键菜单

- 列表图片和画布图片复用同一菜单项生成器与命令分派器。
- 菜单顺序为：内容操作、组织操作、输出操作、危险操作。
- “调整分组”展开未分组、当前已有分组和新建分组；当前分组显示选中标记。
- 列表生成结果菜单包含重新生成、查看大图、设为封面、加入资产管理、下载、调整分组、移动/复制到方向、移入回收站。
- 列表参考图菜单包含查看大图、重命名、调整分组、移动/复制到方向、从当前方向移除。
- 画布节点菜单在共用内容操作之后追加锁定、合并为分组和对齐所选。
- 菜单保持在可视区域内，支持点击菜单外、滚动和 `Escape` 关闭。

## 状态与错误处理

- 拖拽开始时记录被拖动内容键；拖拽结束、取消或落点无效时清理拖影和目标高亮。
- 画布尚未加载、图片节点不存在或持久化失败时不修改可见分组，并显示明确错误。
- 持久化成功后同步画布缓存、列表分段、选中集合和右侧详情。
- 删除、移动/复制、重新生成等操作继续使用现有确认、接口和状态提示规则。

## 测试

- 静态行为测试覆盖统一图标、列表可拖动标记、右键菜单项及共用命令入口。
- 单元测试覆盖分组目标解析、多选拖动集合、同组无操作、未分组清空和新建分组。
- 浏览器验证覆盖拖影跟随、目标高亮、具名分组与未分组落点、列表/画布同步、菜单边界定位、`Escape` 关闭及生成结果快捷操作。
