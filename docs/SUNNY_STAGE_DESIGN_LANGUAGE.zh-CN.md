## 1. 设计方向

Sunny Stage 是克制的工具型平台游戏风格，不是主题乐园风格。

- 保留平台游戏按钮的圆润、厚度、按压感。
- 页面仍然是生产工作台，信息密度要高、层级要清晰、操作要稳定。
- 黑白模式只改变大面积背板、普通表面、文字、边框、网格和弱表面，不改变红、黄、绿、蓝的操作语义。
- 大底板可以有轻微外投影；按钮、输入框、页签、胶囊、图标按钮等小控件不使用外投影。
- 控件的立体感来自内部底部厚度 `inset`，不是外部阴影；但承载内部选中胶囊的页签外壳是容器，不再叠加底部厚度。
- 中间工作区颜色必须跟随当前模式的大背板，白模式为 `#fffef9`，黑模式为 `#080807`。

## 2. 核心颜色

### 2.1 白模式

- 页面背板：`#fffef9`
- 普通浮起控件表面：`#ffffff`
- 柔和控件底：`#f4f1e7`
- 主文字：`#171717`
- 次级文字：`#646464`
- 边框：`rgba(23, 23, 23, .14)`
- 强边框：`rgba(23, 23, 23, .24)`
- 大底板外投影：`0 10px 24px rgba(23, 23, 23, .08)`
- 普通控件内部底部厚度：`inset 0 -4px 0 rgba(0, 0, 0, .06)`

### 2.2 黑模式

- 页面背板：`#080807`
- 普通浮起控件表面：`#121210`
- 柔和控件底：`#171715`
- 主文字：`#fffef9`
- 次级文字：`#b7b5ad`
- 边框：`rgba(255, 254, 249, .14)`
- 强边框：`rgba(255, 254, 249, .24)`
- 大底板外投影：`0 14px 32px rgba(0, 0, 0, .48)`
- 普通控件内部底部厚度：`inset 0 -4px 0 rgba(255, 254, 249, .045)`

### 2.3 语义色

语义色不随黑白模式反转含义，只允许亮度和对比度微调。

- 红色：取消、危险、警告、失败、删除、清空、不可逆操作等负反馈。红色不得作为默认生成、保存、导出、提交按钮色。
- 黄色：提示、注意、等待、排队、需要关注但未到危险级别的状态。黄色强度必须弱于红色。
- 绿色：建议、确认、应用、保存成功、启用、推荐执行、正反馈。生成、保存、应用这类正向确认动作优先使用绿色。
- 蓝色：辅助用色，用于当前工具、画布状态、缩放、运行中、信息辅助、非最终确认的功能入口。
- 白色/黑色：低级别中性按钮色，与当前黑白模式对应。它们表达“不重要、低影响、可轻易撤回”的操作，不用于真正的次操作强调。

### 2.4 使用纪律

- 同一操作组里，红色只能出现于危险或负反馈动作。
- 黄色不能替代红色做危险提示，也不能替代绿色做确认。
- 蓝色不表达“确认完成”，只表达辅助、当前、进行中或工具状态。
- 白/黑按钮不等于“次操作”。次操作如果会影响结果，应根据语义使用蓝色、绿色或黄色；只有无影响取消、关闭、返回、收起这类动作可用白/黑。
- 任何依赖颜色表达的状态，必须同时有文本、图标或标签，不只靠颜色。
- 状态表达不是按钮，不使用整块彩色按钮样式；状态只用白/黑底胶囊承载文本，左侧小圆点使用语义色填充。

## 3. 形状、尺寸与阴影

### 3.1 圆角档位

- `r-xs = 6px`：小标签、状态点、紧凑表格内的小型标记。
- `r-sm = 8px`：小尺寸按钮、小菜单项、紧凑列表项。
- `r-md = 12px`：默认文本按钮、输入框内的小段、资源卡内控件。
- `r-lg = 16px`：多行输入、卡片、普通浮起控件组。
- `r-xl = 20px`：面板、弹窗、小型工作区底板。
- `r-2xl = 24px`：主工作台外壳、大预览区、大底板。
- `r-pill = 999px`：页签、分段控件、开关、胶囊按钮、短状态胶囊。

禁止在同类控件里随意混用圆角。按钮同一尺寸档必须使用同一圆角。

### 3.2 按钮尺寸档

文本按钮宽度一般不得小于高度的 `2.5` 倍；例如 `125x50`、`200x50` 是可接受比例，`50x50` 只能用于纯图标按钮。

- `btn-sm`：高度 `32px`，最小宽度 `80px`，圆角 `10px` 或 `999px`。
- `btn-md`：高度 `40px`，最小宽度 `100px`，圆角 `12px` 或 `999px`。
- `btn-lg`：高度 `50px`，最小宽度 `125px`，圆角 `16px` 或 `999px`。
- `btn-xl`：高度 `56px`，最小宽度 `160px`，圆角 `18px` 或 `999px`。
- `icon-sm`：`32x32px`，仅图标。
- `icon-md`：`40x40px`，仅图标。
- `icon-lg`：`48x48px`，仅图标或强工具入口。

文本按钮如果因为容器太窄而低于比例，应换行、改用图标按钮、移入菜单，或扩大容器；不要压成方形。

### 3.3 大底板

用于页面顶部说明区、主工作台外壳、左侧规则板、弹窗、组件规范卡。

- 圆角：`20px` 到 `24px`
- 背景：当前模式的 `surface`
- 边框：`line` 或 `line-strong`
- 可使用 `panel-shadow`
- 不要嵌套卡片式大面板，避免卡片套卡片

### 3.4 小控件

用于按钮、输入框、图标按钮、状态标签、列表项、工具按钮；页签外壳按第 4 节单独处理。

- 不使用外投影。
- 默认使用内部底部厚度表达按压感。
- 普通控件统一 `inset 0 -4px 0 var(--control-inset)`。
- 彩色按钮使用自身深色底边，例如绿色按钮 `inset 0 -5px 0 var(--green-deep)`。
- 黑模式下普通控件也必须保留内部底部厚度，不能变成只有边框的扁平控件。
- 例外：胶囊页签、分段控件、主题切换等“外壳容器”不加底部厚度，避免外壳厚度和内部选中项厚度叠加。

## 4. 胶囊切换页签

所有切换页签必须统一为完整胶囊体。

- 外壳：完整胶囊，`border-radius: 999px`
- 外壳背景：`soft`
- 外壳边框：`line`
- 外壳不使用外投影，也不使用内部底部厚度；它只是承载选中胶囊的平底容器。
- 选中项：内部胶囊，`border-radius: 999px`
- 选中项使用语义色和深色底边，厚度只出现在选中项上。

适用范围：

- 黑白模式切换
- 顶部功能页签
- 列表/画布等工作台视图切换
- 参数模式切换，例如精修/变体
- 资源分类切换
- 生成模式切换
- 时间线显示模式切换

禁止：

- 同一页面混用按钮式页签、裸文字页签、下划线页签和胶囊页签。
- 页签选中态只靠文字加粗。
- 页签外壳不完整，只让单个按钮浮在背景中。
- 外壳和选中项同时都有底部厚度，形成双层厚度或双层阴影。

## 5. 按钮

### 5.1 推荐/确认按钮

- 使用绿色。
- 用于生成、应用、保存、确认、启用、推荐执行等正向动作。
- 每个工作区同一视觉范围内只允许一个最强推荐动作。

### 5.2 辅助按钮

- 使用蓝色。
- 用于当前工具、打开辅助面板、运行中、缩放、画布状态、非最终确认的功能入口。
- 蓝色按钮不能替代绿色确认，也不能替代红色危险。
- “生成视觉指导图”属于打开持续任务向导的辅助入口，常态统一使用蓝色辅助按钮；运行中继续使用蓝色状态，取消中和失败态可分别切换为黄色、红色反馈。

### 5.3 提示按钮

- 使用黄色。
- 用于查看提示、处理等待、排队、注意事项、轻量提醒。
- 黄色按钮需要文案说明，不要只用颜色表示“需要注意”。

### 5.4 危险/取消按钮

- 使用红色。
- 用于危险、取消任务、删除、清空、失败恢复、不可逆操作。
- 危险动作必须和绿色确认动作保持视觉距离。
- 删除本地文件、清空记录等操作必须二次确认。

### 5.5 低级中性按钮

- 白模式使用白色/浅色表面，黑模式使用黑色/深色表面。
- 仅用于低影响操作：关闭、返回、收起、普通取消、不改变结果的跳出。
- 不用于“次操作”强调；会改变结果的次操作必须按语义选择蓝、绿、黄或红。

### 5.6 图标按钮

- 可以是正方形，但必须是纯图标或图标为主。
- 最小点击目标不低于 `32x32px`，常规工具区优先 `40x40px`。
- 必须有 `title` 和 `aria-label`。
- 图标按钮不承载长文本，不用 `50x50` 容器塞两个汉字。
- 同一导航或工具组优先使用 Lucide 风格的 `24x24` 线性图标，常规描边约 `2px`，使用圆角端点和圆角连接；图标通过 `currentColor` 跟随按钮状态。
- 不得在同一组中混用 Unicode 字符图标、系统字体符号、实心播放三角和线性图标；图标加文字的按钮要为图标保留固定宽度槽位，避免不同图形改变文字起始位置。

### 5.7 禁用按钮

- 降低不透明度到约 `.48`。
- 保留尺寸和布局占位。
- 必须使用真实 `disabled` 语义或不可点击语义。

## 6. 输入控件

适用：单行输入、路径输入、数字输入、搜索框、下拉选择、多行文本。

- 外形优先胶囊或大圆角矩形。
- 单行输入和选择器使用 `999px` 圆角。
- 多行文本使用 `16px` 到 `18px` 圆角。
- 普通状态使用 `line` 边框和 `raised` 表面。
- 错误状态使用红色边框，并在控件附近给出可恢复说明。
- 成功状态使用绿色边框或绿色状态标签。
- 注意状态使用黄色提示，不能伪装成错误。
- 不要只用 placeholder 作为标签，复杂输入必须有显式 label。

## 7. 开关、复选、滑杆和进度

### 7.1 开关

- 外壳使用胶囊。
- 开启态内部圆点使用绿色。
- 黑白模式只改变外壳和文字，不改变开启态绿色。

### 7.2 复选

- 选中态使用绿色。
- 勾选视觉区域不小于 `24px`，点击目标不小于 `44px`。

### 7.3 滑杆

- 轨道使用 `soft` 背板。
- 已完成部分使用蓝色。
- 拖拽点使用 `raised` 表面和内部底部厚度。

### 7.4 进度

- 等待或排队使用黄色。
- 执行中使用蓝色。
- 完成使用绿色。
- 失败或取消使用红色。
- 进度必须配文本，不只靠颜色。
- 独立状态标签不使用进度条或按钮外观；只在左侧状态点上使用语义色。

## 8. 面板、弹窗、抽屉

### 8.1 面板

- 大工作区面板可以有轻外投影。
- 面板内部控件不使用外投影。
- 面板之间用边框和布局分区，不用大量阴影堆叠。
- 中间工作区跟随当前模式背板，不使用独立彩色底。
- 项目总览里的进度统计属于面板级摘要，不做成挤在左侧的短胶囊；当统计项超过四项时应横跨所在进度面板，并用稳定网格分摊宽度。

### 8.1.1 顶栏资料入口

- 本地资料入口固定贴齐标题栏右侧，并在标题栏高度内垂直居中。
- 顶栏功能切换和主题切换保持各自的网格位置，不应把本地资料入口挤到中间列。
- 头像和资料文字组成一个稳定宽度控件，长名称和连接状态用省略号处理。

### 8.1.2 固定项目工作台边界

- 固定项目工作台不得直接贴住顶栏、侧栏、状态栏或视口边缘，桌面端至少保留 `12px` 安全间距，窄屏也要保留可见边线。
- 工作台标题栏和内容区各自是完整面板：标题栏负责上下文和操作按钮，内容区负责列表、画布、设置或回收站，不允许内容面板的边框被父容器裁切。
- 标题栏动作区、筛选条和统计条允许换行或横向滚动，不能挤压标题、遮挡详情栏或造成边线丢失。
- 列表 + 详情、画布 + 设置、配置 + 部署这类分栏模块必须用稳定网格和 `gap` 区分，不依赖贴边边框来表达层级。
- 面板内的滚动区域必须预留底部内边距和 `scrollbar-gutter`，确保底部按钮、文件选择器、状态行和圆角完整可见。
- 含摘要条的页面用网格行管理摘要和主内容，不用固定高度 `calc()` 从内容区扣除统计条。

### 8.1.3 固定处理工作台边界

- 图片处理、视频处理和序列帧提取的右侧内容区采用内部滚动时，滚动视口四周至少保留 `8px` 安全边距，滚动条与内容面板之间也要有清晰间隔。
- 内容面板的圆角、外投影和激活描边必须完整落在滚动视口内，不能只在右侧补白而让顶部、左侧或底部被裁切。
- 每个步骤面板都要裁切内部标题背板和内容背景，任何内部背板都不能以直角越过父面板圆角；面板自身的外投影与外部激活描边保持可见。
- 同级步骤面板之间保持统一垂直间距；步骤标题、说明和面板边线不能触碰滚动视口边缘。
- 窄侧栏的多按钮操作区必须使用可收缩网格或弹性布局，覆盖全局按钮最小宽度，确保末项按钮和侧栏边框完整可见。

### 8.1.4 项目侧栏层级

- `资产生产` 和 `资产处理` 在项目侧栏中都是分组标题，不使用按钮外观，也不承载点击行为。
- `资产生产` 下固定排列 `图片生成`、`视频生成`、`音频生成`、`生成历史`；`资产处理` 下排列具体处理工具。
- 分组标题与子按钮通过缩进和左侧引导线表达层级，当前页面只高亮对应子按钮，不高亮整个分组。
- 已经放入侧栏的生产媒体入口不在工作台标题栏重复显示同一套页签；标题栏只保留工作台状态和当前视图操作。

### 8.1.5 可折叠导航轨道

- 项目主导航、风格方向导航等长期占用横向空间的侧栏，通过右侧分隔边缘提供折叠能力；首次使用默认展开，用户主动切换后刷新页面必须恢复上次状态，不在侧栏正文中额外增加常驻按钮行。
- 分隔边缘提供连续且可命中的窄热区。鼠标悬停或键盘聚焦时，整条边线切换为蓝色强调，并在边线中部浮出 `32px` 以上的中性折叠/展开图标按钮；按钮使用统一线性箭头，并提供 `title`、`aria-label`、`aria-expanded`。
- 项目主导航折叠后仅保留居中的功能图标和层级分隔线；风格方向导航折叠后仅保留可点击的方向预览图，底部创建入口收为加号图标。所有图标入口必须通过提示文本保持可理解。
- 展开与折叠只改变导航宽度和信息密度，不改变当前选中对象、禁用状态或业务状态。方向确认使用绿色勾选胶囊，紧凑状态下收为缩略图角落的勾选标记，选中态仍使用蓝色边框体系。
- 折叠动画使用约 `160ms` 的宽度/网格过渡；遵循 `prefers-reduced-motion`。窄屏自动紧凑布局时隐藏边缘按钮，避免允许用户强制展开后挤压工作区。
- 工作台已经由项目导航明确标识当前模块时，不重复保留只承载模块中英文名称的独立标题栏；释放出的垂直空间应交给主内容和工具上下文。
- 风格探索内容详情采用工作区内右侧浮窗，上、下、右至少保留可见安全边距；浮窗的垂直范围限定在主内容区域内，顶部避开方向摘要与页签/视图工具栏，画布模式底部避开状态栏。面板使用完整边框、圆角和轻投影，内部标题/关闭区固定，正文独立滚动。右上角关闭按钮必须可见且具备无障碍名称，关闭同时取消当前内容或画布对象选中，但不影响批量勾选。
- 资产生产的生成与结果详情浮窗使用单一面板表面：只允许最外层浮窗提供底板、边框、圆角和投影，内部标题区与滚动正文不得再增加贯穿全高的第二层白色或彩色底板。浮窗上、右、下边距使用同一安全间距，让标题区可上移到工作台上边缘附近；正文保持透明并直接承载参数分组，不新增装饰性底板。

### 8.2 弹窗

- 使用 `surface` 背景、`line-strong` 边框、`panel-shadow`。
- 标题、关闭按钮、主要内容、底部动作区必须清晰分组。
- 关闭按钮必须显式可见。
- 编辑类弹窗不要点击遮罩关闭，避免输入丢失。
- 底部动作按钮按语义排列：低级取消用中性，确认保存用绿色，危险动作用红色并分离。
- 资源选择弹窗的勾选、分组折叠和异步数据刷新不得重置内容滚动位置、焦点或弹窗开关状态；优先局部更新状态，确需重建时必须显式保存并恢复这些视图状态。
- 多组生成设置在桌面弹窗中优先使用紧凑双栏网格，让模式、模块和参数在常规高度内一次可见；只有窄屏或内容确实超出时才回落单栏滚动。

### 8.3 抽屉

- 和弹窗同样使用大底板规则。
- 只用于侧向配置或资源详情，不用于普通提示。

## 9. Toast、Tooltip、空状态

### 9.1 Toast

- 使用普通控件表面。
- 保留内部底部厚度。
- 成功用绿色、失败/取消用红色、等待用黄色、运行中用蓝色。
- 必须有文字和状态点或图标。
- 不抢焦点，使用 `aria-live="polite"`。

### 9.2 状态标签

- 状态标签用于表达等待、运行中、已保存、失败、不可用等状态，不用于触发动作。
- 状态标签底色跟随黑白模式：白模式为白底或浅表面，黑模式为黑底或深表面。
- 状态标签不使用按钮样式，不使用整块彩色背景，不使用底部厚度，不表现为可点击。
- 文本左侧必须有小圆点，圆点填充语义色：等待/排队为黄色，运行中为蓝色，成功/已保存为绿色，失败/取消为红色，不可用为中性色。
- 状态标签仍需保留文本，不能只显示颜色点。

### 9.3 Tooltip

- 用于解释图标按钮或短状态。
- 黑白模式下不使用高对比大浮层，不使用大面积装饰。
- 文字短、位置稳定，不遮挡被解释控件。

### 9.4 空状态

- 使用虚线边框或轻边框。
- 文案短，给出下一步动作。
- 下一步如果是建议动作用绿色；只是打开辅助入口用蓝色；无影响关闭/返回用中性。
- 不做大型插画或营销式说明。

## 10. 列表、表格、资源卡

### 10.1 列表项

- 高度稳定，避免文本变化导致布局跳动。
- 左侧预览或图标固定尺寸。
- 右侧状态使用白/黑底状态胶囊，左侧状态点填充语义色。
- 文本溢出用省略号，必要时 tooltip 提供完整信息。

### 10.2 表格

- 表头使用 `soft` 背板。
- 行分隔使用 `line`。
- 数字和进度使用等宽数字或稳定宽度。
- 状态列必须使用状态标签，保留文本和左侧语义色圆点，不使用按钮样式。
- 危险行操作用红色图标或红色文本按钮，不放在默认操作位。

### 10.3 资源卡

- 预览区域固定比例。
- 素材主体不要被裁切。
- 文件名、尺寸、来源类型至少显示其中两项。
- 卡片自身可以是轻面板；卡内按钮仍遵守无外投影和尺寸比例。
- 项目卡等包含路径与右侧动作的卡片必须使用可收缩内容列；长文本省略，状态标签与动作保持固定，不得越过卡片边框或扩大内部网格轨道。
- 结果卡的底部操作只直接保留高频主动作和状态动作；其余命令进入方形“更多操作”菜单，卡片内部禁止出现横向滚动条，菜单和按钮不得被卡片圆角或固定高度裁切。
- 所有图片缩略图的图片主体都必须可点击并支持键盘聚焦，统一打开全局大图预览；悬停放大图标只作提示并与主体共用同一点击入口，不使用嵌套按钮。缩略图和大图均按原比例完整自适应，不裁切主体。
- 全局大图在 1 倍时保持居中查看；放大后以 `grab` 表达可平移，拖动时切换为 `grabbing`。平移只作用于图片本身并受视口边界限制，不移动标题、底板工具、命名栏或其他浮层控件；缩放复位、换图和关闭时清除位移。

### 10.4 提示词模板选择器

- 模板入口紧贴提示词输入框下方，使用低强调度的完整宽度辅助按钮，不占用模型参数区或生成主动作位置。
- 模板选择器使用视口居中的独立工作台弹窗，不受右侧生成浮层宽度裁切；标题、五分类胶囊页签、模板列表、提示词预览和底部操作区保持稳定层级。
- 桌面端内容区采用左侧紧凑模板列表、右侧完整预览的双栏结构，两栏独立滚动；窄屏回落为单列，分类页签允许横向滚动但不换行。
- 模板卡只展示名称、简述、构图协议和可选推荐模型标签；推荐标签使用中性状态胶囊，不表现为自动切换模型的动作。
- 提示词预览允许选择和复制文本；只有底部“应用模板”按钮写入提示词框。弹窗不因点击遮罩关闭，支持显式关闭、取消和 `Escape`，关闭后焦点返回模板入口。

## 11. 画布和预览区

- 中间画布背板跟随当前黑白模式。
- 透明检查、缩略图和素材内部可以显示棋盘格。
- 画布网格使用弱对比线，不抢素材主体。
- 辅助控件优先贴边或角落，不遮挡主体。
- 缩放、定位、画布工具优先使用蓝色作为辅助状态。
- 视觉指导图的细节密度使用与生成模式一致的紧凑分段控件，固定提供“精简 / 标准 / 丰富”三项；默认精简项同时标注“小游戏推荐”，说明文字强调手机小尺寸的轮廓与大色块可读性，不用抽象的“质量高低”描述细节档位。
- 三栏画布工作台按一个连续面板处理：仅最外层工作台外壳保留圆角，内部上下文栏、画布栏和设置栏保持直角，并用单像素分隔线表达列边界。
- 画布顶部工具栏的行高必须覆盖控件高度和上下安全留白，按钮不能贴住工具栏边线；文字工具保持内容宽度，撤销、重做、缩放等纯图标工具固定为正方形，缩放数值使用稳定宽度避免布局跳动。
- 画布工具栏常态按钮使用当前模式的白色控件底和中性文字，悬停只做浅蓝提示；只有当前生效的选择、框选等模式按钮使用蓝色激活态，瞬时命令和缩放按钮不因属于画布工具而默认染蓝。
- 自动整理按钮在画布存在可整理内容时保持可用：无选择整理全画布，有选择只整理所选；分组作为整体、锁定对象作为障碍保留原位。整理结果和新节点默认位置都必须避开现有内容，不允许节点或分组互相覆盖。
- 处理画布底部的纯图标按钮固定为正方形，不能继承文字按钮的全局最小宽度；底板模式使用完整胶囊分段控件，未选项为白色控件底、选中项为蓝色，颜色选择器只在纯色模式下展开。
- 流程确认按钮启用时使用绿色；禁用时使用中性表面和中性文字，并移除绿色、蓝色或黑色的激活阴影，不能让禁用按钮看起来仍可执行。

## 12. 动效

- 微交互时长：`150ms` 到 `220ms`。
- 只动画颜色、透明度、`transform`，不动画布局尺寸。
- 主题切换可以 crossfade，但不要闪白或闪黑。
- 重要操作要有按压反馈。
- 必须尊重 `prefers-reduced-motion`。
- 远端生成提交阶段使用覆盖当前业务弹窗的半透明忙碌层，保留原界面作为上下文但拦截重复操作；忙碌层以单个旋转状态环、无确定百分比的流动进度线、状态标题和真实等待原因构成，不虚构上传百分比或精确阶段。
- 生成进度列表只为当前 `提交中 / 排队中 / 生成中` 节点提供蓝色旋转外环、轻微呼吸底色和流动进度线，等待节点保持静止，完成和失败节点立即停止动画。减弱动效模式下移除旋转、呼吸和流动，只保留状态色与文字。

## 13. 选择行为

- 工作台界面默认禁用文本和图片框选，避免拖拽、框选、画布操作时出现浏览器原生选区。
- `body` 或应用根节点默认使用 `user-select: none`。
- 图片、预览图、图标和装饰图形禁止拖拽和框选，图片元素同时设置 `user-select: none` 和 `-webkit-user-drag: none`。
- 输入框、文本域、路径输入、搜索框、可编辑文本、代码/日志等需要复制内容的区域必须恢复 `user-select: text`。
- 禁用框选不能破坏输入框内的光标、复制、粘贴、全选和键盘操作。

## 14. 黑白模式验收清单

- 大面积背板只在 `#fffef9` 和 `#080807` 之间切换。
- 中间工作区不使用独立蓝底、卡其底或其他彩色底。
- 普通控件黑白模式都保留内部底部厚度。
- 小控件不使用外投影。
- 大底板黑白模式都可以有轻外投影。
- 胶囊切换页签全局统一为同一种完整胶囊体，且只有内部选中胶囊有底部厚度，外壳不加厚度。
- 状态标签全局统一为白/黑底 + 左侧语义色圆点 + 文本，不使用彩色按钮块。
- 红色只用于危险、取消、警告和负反馈。
- 黄色只用于提示、等待和弱警示。
- 绿色用于确认、建议、保存、生成、启用和正反馈。
- 蓝色用于辅助工具、当前状态、运行中和画布相关状态。
- 白/黑按钮只表达低重要性，不承担真正次操作。
- 文本按钮宽度一般不小于高度的 `2.5` 倍；图标按钮才可以是正方形。
- 界面文本和图片默认不可框选，输入框、文本域和可编辑内容除外。
- 文本对比度满足可读性要求。
- 焦点态、禁用态、错误态、加载态在黑白模式下都可辨认。

## 15. 更新流程

后续设计调整按以下顺序推进：

1. 先更新本文档，明确规则变化。
2. 再更新设计模板，展示新规则。
3. 最后改项目源码。
4. 每次前端源码改动至少运行 `node --check app\app.js`。
5. 如果规则和实际使用冲突，优先修订本文档，再调整实现。
